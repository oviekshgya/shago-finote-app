QUICK START

To run and debug on Android:

  1. Connect Android device via USB (or start emulator)
  2. Enable USB debugging on device
  3. Run:
     
     npm run dev:android

That's it! The script handles everything:
  ✓ Checks prerequisites
  ✓ Installs dependencies
  ✓ Starts Metro bundler
  ✓ Builds debug APK
  ✓ Installs to device
  ✓ Launches app
  ✓ Shows debug commands

No need to open multiple terminals anymore!

USEFUL COMMANDS

Development:
  npm run dev:android       Start development environment
  npm start                 Start Metro bundler only
  npm run android           Build and install APK (manual)
  npm lint                  Check code

Debugging:
  adb logcat                View all logs
  adb devices               List connected devices
  adb shell pm clear ...    Clear app data
  adb shell am start -n ... Launch app manually

Building:
  cd android && ./gradlew assembleDebug && cd ..
  cd android && ./gradlew clean && cd ..
