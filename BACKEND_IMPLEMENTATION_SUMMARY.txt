QUICK START

1. Start with Docker (Recommended):
   cd backend
   docker-compose up -d

   Services available:
   • API: http://localhost:5000
   • Swagger: http://localhost:5000/swagger
   • PgAdmin: http://localhost:5050

2. Local Development:
   cd backend/ShagoFinote
   dotnet run

   Or with local PostgreSQL:
   Update appsettings.Development.json connection string first

  {

TROUBLESHOOTING

Q: Port 5000 already in use?
A: Change port in docker-compose.yml or kill process: lsof -i :5000

Q: Database connection failed?
A: Check PostgreSQL is running, verify connection string in appsettings.json

Q: JWT token invalid?
A: Ensure token not expired (1 hour) and secret matches

Q: Docker image too large?
A: Multi-stage Dockerfile already optimized, ~200MB final image

Q: Logs not appearing?
A: Check logs directory: ShagoFinote/logs/ or use: docker-compose logs -f
