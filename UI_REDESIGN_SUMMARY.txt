WHAT'S NEW - MODERN DESIGN SYSTEM

Color Palette (5 Primary + 8 Semantic):
  Primary:    Emerald #10B981 (replaced BCA red #c9152a)
  Secondary:  Teal #06B6D4
  Accent:     Amber #F59E0B
  Background: Deep Navy #0F172A → Charcoal #1E293B (gradient)
  Semantic:   Income (green), Expense (red), Pending (amber)

Typography Hierarchy:
  H1 (32px)   - Screen titles like "💰 Keuangan Anda"
  H2 (28px)   - Section headers
  H3 (24px)   - Card titles
  H4 (20px)   - Subheadings
  Body (16px) - Main text
  Label (14px)- Form labels
  Small (12px)- Secondary text
  Tiny (11px) - Captions

Spacing System (4px Grid):
  xs (4px)   → Tiny gaps
  sm (8px)   → Small spacing
  md (12px)  → Medium
  lg (16px)  → Standard padding
  xl (24px)  → Large sections
  xxl (32px) → Major spacing

Professional Shadows:
  Small:   0 1px 2px (subtle)
  Medium:  0 4px 6px (standard)
  Large:   0 10px 15px (emphasis)
  Glow:    Emerald glow effect

Border Radius (Modern Curves):
  xs (4px)    - Small buttons
  sm (8px)    - Form elements
  md (12px)   - Cards
  lg (16px)   - Prominent cards
  xl (20px)   - Modals
  full (999px)- Pills & circles

REUSABLE COMPONENTS CREATED

1. ModernCard (3 Variants)
   ├─ default:  Clean surface with border
   ├─ gradient: Emerald accent border
   └─ elevated: Drop shadow for depth
   
   Usage:
   <ModernCard variant="gradient" padding={spacing.lg}>
     {children}
   </ModernCard>

2. ModernButton (4 Variants + 3 Sizes)
   ├─ Variants: primary, secondary, outline, ghost
   ├─ Sizes:    sm (36px), md (48px), lg (56px)
   └─ Features: Icon support, disabled state, fullWidth
   
   Usage:
   <ModernButton
     label="Save"
     onPress={handleSave}
     variant="primary"
     size="md"
   />

3. ModernInput (Full-Featured)
   ├─ Features: Icon, validation, password toggle
   ├─ Support:  Multiline, maxLength, keyboard types
   └─ States:   Focus, error, disabled
   
   Usage:
   <ModernInput
     label="Amount"
     value={amount}
     onChangeText={setAmount}
     icon="💰"
     error={error}
   />
